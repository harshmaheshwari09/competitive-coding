# 560. SUBARRAY SUM EQUALS K

* Question: https://leetcode.com/problems/subarray-sum-equals-k/description/
* Solution: [here](Solution.java)
* Testing: [here](SolutionTest.java)
* Tags: #array #hashmap #prefix_sum
* Complexity: Time: O(n), Space: O(n)

## Problem

Given an array of integers `nums` and an integer `k`, return the total number of contiguous subarrays whose sum equals `k`.

## Examples

### Example 1

```text
Input: nums = [1,1,1], k = 2
Output: 2
```

### Example 2

```text
Input: nums = [1,2,3], k = 3
Output: 2
```

## Constraints

```text
1 <= nums.length <= 20000
-1000 <= nums[i] <= 1000
-10000000 <= k <= 10000000
```
